# Responsive Website - Simran Singh

A responsive, one-page website built with HTML, CSS, and JavaScript. No frameworks or dependencies.

## Key Features

- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Smooth scrolling & hamburger menu
- ✅ Animated card reveals on scroll
- ✅ Active navigation highlighting
- ✅ Professional, clean design
- ✅ Vanilla JavaScript 

## Files

| File | Purpose |
|------|---------|
| `index.html` | HTML structure & content |
| `style.css` | Styling & responsive design |
| `script.js` | Navigation & animations |

## Page Sections

1. **Navbar** — Fixed header with navigation
2. **Home** — Hero section with profile & CTA buttons
3. **About** — Experience, education & bio
4. **Experience** — Technical skills & work history
5. **Projects** — Project cards (Student Database, MIS Dashboard, Responsive Website)
6. **Skills** — Skill cards (MySQL, HTML, CSS, JavaScript, Python)
7. **Contact** — Email, GitHub, LinkedIn
8. **Footer** — Copyright & links

## How to Use

1. Open `index.html` in any modern browser
2. That's it! No build tools or installation needed

## How to Customize

### Update Info
- Change name in navbar, home section, footer
- Update role, about text, experience details
- Replace image URLs (currently using placeholders)
- Update contact info & social links

### Change Colors
Edit CSS variables at the top of `style.css`:
```css
:root {
  --white: #ffffff;
  --black: #111111;
  --grey: #555555;
  /* ... etc ... */
}
```

### Replace Images
Find these placeholder URLs in `index.html` and replace:
- Profile: `https://via.placeholder.com/300`
- About: `https://via.placeholder.com/280x340`
- Projects: `https://via.placeholder.com/400x200?text=...`
